# qq-netease-music

给官方 QQ 机器人用的 `/网易云` 点歌 skill：发歌名搜歌、回序号选歌，机器人发出一条指向**你自己域名下** GitHub Pages 全屏播放页的链接，用户在 QQ 里点开就能听——音频由用户浏览器直连音乐源拉流，机器人只发链接、零媒体转发，多群共用也不压服务器；选歌成功后搜歌列表会自动撤回，聊天框里只留最终结果。网易云歌曲链接或 ID 发给机器人可直达出链接。

播放页链接长这样（把域名换成你自己的）：

```
https://play.<你的免费域名>/?id=2652647226&v=4
```

## 功能清单

- 🎵 `/网易云 <歌名>`：Meting 接口搜歌 → 编号列表（歌名+歌手，最多 10 首）→ 回序号选歌（会话 5 分钟、按人隔离，选错保留会话）
- 🔁 搜歌自动重试：上游搜索接口会间歇抽风回空，模块内置 3 次重试 + 总预算封顶，轨迹写审计
- 🔗 链接/ID 直达：网易云歌曲链接（含分享文案里嵌的）或纯数字歌曲 ID 直接出播放链接，跳过搜索
- 🧹 答后撤回：选歌成功、最终链接发出后，自动撤回搜歌列表，最终消息永不撤
- 📱 iOS 风全屏播放页：虚化封面背景、可拖进度条、±15 秒快退快进、点封面进歌词页（滚动高亮）、循环播放
- 🚫 服务器零媒体经手：机器人与 Pages 都不下载、不转发音频，流量在用户浏览器与音乐源之间直连

## 快速开始

1. 先跑 `node smoke-test.mjs`（离线自检，32 项全绿），再 `node example-host.mjs` 看假 sender 干跑全流程；
2. 照 [SKILL.md](./SKILL.md) 的「**(B) 播放页部署向导**」从零部署播放页：领免费域名（dnsneko）→ 建 GitHub 仓库放播放页 → 绑自定义域名 → 把地址填回 `music.mjs` 的 `PLAYER_PAGE` 常量——向导是编号步骤、每步标明由用户还是 agent 动手，照着走即可；
3. 机器人侧接线照 SKILL.md 的「快速接入」与「(A) 机器人侧接线」挂进你的消息循环。
